协议说明 / 使用要求

运行要求：Web Bluetooth 需要 HTTPS 或 http://localhost 安全上下文，以及桌面 Chrome / Edge（或 Android Chrome）。 直接用 file:// 打开、iOS Safari、Firefox 均不可用。若本地打开，可在仓库目录执行 python -m http.server 8000 -d web 后访问 http://localhost:8000。

GATT：主服务 0xFF00（0000ff00-0000-1000-8000-00805f9b34fb）， 长值特征 0xFF01（Read / Write Request），电池电压 0xFF02。

0x91 同步时间（写入 0xFF01，最少 8 字节；本页按 HMCLOCK 原版发 12 字节）：

字节含义
[0]0x91
[1..2]年，uint16 小端（2026 → EA 07）
[3]月，0-based（0=1月 … 11=12月）
[4]日，1-based
[5..7]时 / 分 / 秒
[8..11]星期 / 农历年-2020 / 农历月 / 农历日（HMCLOCK 原版字段；本固件忽略并自行重算农历、星期、节气、节日）

例：2026-11-19 09:30:00 → 91 EA 07 0A 13 09 1E 00。 固件收到后立刻重算农历并写入 SPI Flash，蓝牙断开后完全独立走时。

0xFF01 回读（连接期间固件每秒刷新一次，13 字节）：

字节含义
[0..1]年，uint16 小端
[2] / [3]月（0-based） / 日（1-based）
[4..6]时 / 分 / 秒
[7..10]cal_minute，int32 小端：距上次对时经过的分钟数，-1=从未对时
[11..12]当前时钟修正值（int16 小端低 16 位）

0x92 时间校准：先读取 cal_minute（需 ≥ 2880，即对时满 2 天，否则样本太短）， 然后轮询 0xFF01 等设备分钟跳变，比较「设备跳变时刻」与「系统跳变时刻」算出秒差， 写入 92 <diff_lo> <diff_hi> 00（diff 为有符号 16 位小端，负数表示设备慢了）。 固件按 diff/cal_minute 调整 1 秒节拍，长期抵消晶振漂移。

手机替代方案：nRF Connect 连接后对 0000ff01-0000-1000-8000-00805f9b34fb 写上述 12 字节 0x91 包即可，或用电脑执行 python tools/sync_time.py。
