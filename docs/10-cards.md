# 10 多卡片（时钟 / 天气 / TODO / 画册）

副屏可以在几种"卡片"之间切换，上位机里点一下就换。

| 卡片 | 谁画的 | 说明 |
|---|---|---|
| **监控面板** | 固件 | 原来的 CPU/内存/网速/温度面板 |
| **纯时钟** | 固件 | 大号 HH:MM + 秒 + 日期星期，每秒只刷变化的字 |
| **天气** | 电脑 | 城市、温度、天气描述、高低温/湿度 + 图标 |
| **TODO** | 电脑 | 最多 6 条，带勾选框，已完成带删除线 |
| **画册** | 电脑 | 任意图片 → 自动裁切 + 黑白抖动 |

> 为什么天气/TODO/画册由电脑画？因为价签的 RAM 只剩二十几 KB，
> 放不下中文字库和整屏缓冲；电脑渲染好 320×240 黑白图推过去，固件只管贴图，
> 中文、字体、排版全在电脑上解决。

## 1. 怎么用

上位机 → **显示卡片** 页签：

1. 选卡片（监控面板/纯时钟/天气/TODO/画册）——点选即下发
2. 天气：填城市（中文即可，如 `北京`），数据来自 wttr.in，约 20 分钟更新一次
3. TODO：最多 6 条，勾"完成"会显示成勾选框 + 删除线
4. 画册：选一张图，自动裁成 320×240 并做 Floyd–Steinberg 黑白抖动
5. 点「应用卡片」重发一次；想让卡片断电保留，再点底部「保存到 Flash」

后台推送（`PcMonitorAgent`）也会读同一份配置，所以关掉上位机后：
- 天气每 20 分钟自动刷新
- TODO / 画册改动后自动重推
- 换了卡片自动跟随

配置文件：`%LOCALAPPDATA%\pcmonitor\gui_config.json` 的 `card / city / todo / photo` 字段。

## 2. 协议

| 命令 | 内容 | 说明 |
|---|---|---|
| `0xC8` | `[1]` = 0..4 | 切换卡片（0 监控 / 1 时钟 / 2 天气 / 3 TODO / 4 画册） |
| `0xCB` | `[1..2]` 宽 · `[3..4]` 高 | 图像开始：清屏，准备接收 1bpp 位图 |
| `0xCC` | `[8..]` 128 字节 | 图像数据，顺序追加；每 1600 字节（40 行）自动上屏 |
| `0xCD` | — | 图像结束，补齐最后一条带 |

位图格式：每行 `(宽+7)/8` 字节，高位在左，**1 = 亮（白）**，0 = 黑。

整屏 320×240 = 9600 字节 = 75 个 `0xCC` 包，约 3 秒传完（期间屏幕从上往下逐条刷出来）。

## 3. 实现细节

- 固件不用整屏缓冲：1600 字节的"条带"缓冲，攒满 40 行就贴一次
- 卡片选择存在配置结构里（`cfg_t.card`），配置版本升到 v2
- 切到同一张卡片不会重绘，避免重连时闪屏
- 图像卡在没有收到图之前显示 `WAITING FOR PC`

## 4. 限制

- 画册是**黑白抖动**，不是灰度；1bit 屏只能这样，效果类似老式电子墨水
- 一屏只能放一张图，换图要重传（约 3 秒）
- 天气依赖 wttr.in，国内偶尔会慢；失败时沿用上一次的数据
