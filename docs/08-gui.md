# 08 上位机配置工具（pc_monitor_gui.py）

通过蓝牙配置副屏的**显示内容、屏幕配色、RGB LED 与灯效规则**，并可保存到副屏 Flash（断电不丢）。

## 1. 运行

```bat
python -m pip install -r requirements.txt
python tools\pc_monitor_gui.py
python tools\pc_monitor_gui.py 18:BC:5A:5A:87:81   :: 指定设备 MAC，省去扫描
```

程序启动后会自动扫描 `DLG-CLOCK-*` 并连接，同时持续推送电脑状态（等同于 `pc_agent.py`）。

> **关于连接占用**：DA14585 只支持 1 条 BLE 连接。如果后台计划任务 `PcMonitorAgent`
> 正连着副屏（屏幕上有数据），本工具启动 6 秒后会自动暂停该任务并接管连接；
> 关闭本工具时会自动恢复后台推送。也可以直接点顶部「接管连接」手动切换。
> 若工具被强制结束、后台推送没有恢复，下次打开本工具会自动修复，也可执行
> `schtasks /Change /TN PcMonitorAgent /ENABLE` 后再 `schtasks /Run /TN PcMonitorAgent`。

## 2. 页签说明

| 页签 | 能做什么 |
|---|---|
| **显示内容** | 勾选要在副屏上显示的项目（时钟/CPU/GPU/内存/C 盘/网速/网络名/主机名/温度） |
| **屏幕配色** | 背景、主文字、次文字、分隔线、进度条低/中/高、时间、强调色，点色块用取色器 |
| **LED 控制** | 总开关；7 种颜色（红/绿/蓝/黄/青/紫/白）；闪烁次数与周期；4 个自定义预设 |
| **LED 规则** | CPU 过热（阈值/颜色/次数/冷却秒）；整点报时（开关/颜色/次数） |
| **固件升级** | 选 `.bin` → 显示版本/CRC → 进度条推送，完成后自动重连 |
| **显示卡片** | 屏幕在 监控面板/纯时钟/天气/TODO/画册 之间切换（见 [10-cards.md](10-cards.md)） |

底部按钮：

- **应用到副屏**：立即下发（不写 Flash，断电后恢复上次保存的配置）
- **保存到 Flash**：下发并写入副屏 SPI Flash
- **读取配置**：从副屏读回当前配置（会短暂暂停数据推送）
- **恢复默认**：恢复出厂外观与 LED 规则

本地还会保存一份 `%LOCALAPPDATA%\pcmonitor\gui_config.json`，便于下次打开时恢复界面状态。

## 3. 打包成 EXE（双击即用）

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build_gui_exe.ps1
```

产物：`dist\PcMonitorGUI.exe`（约 32 MB，单文件，双击运行）。
首次启动会自动解压，约 2~5 秒。

前提：本机 Python 已装 `pyinstaller`（脚本会自动用它打包）：

```bat
python -m pip install pyinstaller
```

> EXE 只在本机 Python 环境里打包；换电脑要重新打包（或直接发这个 exe 给同是 64 位 Windows 的机器）。
> 打包参数已包含 `bleak` / `winrt` / `PIL` 的隐藏依赖，BLE 扫描与写入都正常。

## 4. 已知限制

- RGB 灯是 3 路 GPIO 开关（无 PWM），颜色只能取 **7 种组合**，不能做渐变/亮度调节。
  取色器只用于**屏幕配色**，LED 颜色是固定 7 色按钮。
- 配置变更时副屏会整屏重绘一次，约 0.2~0.5 秒（只在点“应用”时发生）。
- 配置保存在 SPI Flash 的 `0x3B000` 扇区（256 字节）；Flash 容量不足时保存会失败，但不影响运行。

## 4. 协议（0xC0~0xC7，均写 0xFF01 长值特征）

| 命令 | 载荷 | 说明 |
|---|---|---|
| `0xC0` | `[1..2]=字段掩码 LE` | 显示字段 |
| `0xC1` | `[1]=调色板索引 [2..3]=RGB565 LE` | 单项颜色 |
| `0xC2` | `[1]=LED 开关 [2]=颜色位 [3]=次数 [4]=周期(100ms)` | 立即播放 |
| `0xC3` | `[1]=阈值℃ [2]=颜色 [3]=次数 [4..5]=冷却秒 | 过热规则 |
| `0xC4` | `[1]=开关 [2]=颜色 [3]=次数` | 整点规则 |
| `0xC5` | `[1]=槽位 [2]=颜色 [3]=次数 [4]=周期 [5]=动作(0存/1播/2清)` | 自定义灯效 |
| `0xC6` | `[1]=0 保存 Flash / 1 恢复默认 / 2 立即重绘` | 配置操作 |
| `0xC7` | 无 | 把 `cfg_t` 写回特征，随后读取特征即可回读 |

调色板索引：0 背景、1 主文字、2 次文字、3 分隔线、4~6 进度条低/中/高、7 时间、8 强调色。
